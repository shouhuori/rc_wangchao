# 供应商 Driver 调整

用户明确要求一个供应商系统对应一个实现类。已有代码实现授权继续适用。

- 一个供应商协议类可用于该系统的多个账号/环境连接；不同供应商分别实现。
- 类声明 API 操作、必填业务输入、请求方式/路径和幂等能力。prepare 构建请求，interpret 读取完整 HTTP 响应并返回状态与业务输出。
- 数据库 API 记录增加 operation，后台只允许选择代码声明的操作。method/path 为展示缓存，发布时重新从代码解析。超时与启用状态可配置，协议和幂等声明不能被表单覆盖。
- 发布版本固定 driver ID 与 operation；不兼容协议更新使用新的 Driver ID。既有连接不允许切换协议类，避免旧任务读取其他供应商的凭证。
- 旧通用 Driver 仅支持已接收事件的快照执行与原连接密钥轮换，不再出现在新连接选项中。历史快照不改写。
- 演示实现为 DemoCrmDriver、DemoInventoryDriver、DemoSmsDriver。它们不是任何真实产品的协议。

执行：先验证操作选择/协议锁定/供应商请求差异的失败测试，再实现类、发布校验与后台表单；最后迁移本地演示连接、发布新版本，运行 SQLite/MySQL 测试和本地 HTTP 联调。

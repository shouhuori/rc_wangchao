# 通知分发系统设计

目标：接收统一业务事件，持久化后异步分发；提供可操作的中文后台与完整调用链。技术栈 Laravel、MySQL、Redis、Blade。

## 领域
事件定义由事件工作流模板承载；语义 ID 稳定。模板包含任务 DAG，每个任务包含请求步骤 DAG。发布创建不可变版本，接收时固定版本；供应商接口及连接参数一并快照。凭证加密保存，发送时读取最新凭证。每个具体供应商系统使用独立 Driver 类；同一系统的多个账号连接复用该类。Driver 使用稳定 ID 注册，类路径不进入数据库。API 记录绑定 operation，协议、认证与响应解析由类实现；保存和发布时校验代码中是否存在此操作。
事件实例 -> 任务实例 -> HTTP 步骤 -> 追加的执行尝试。转换整体事务；步骤是重试单位。事件总体投递状态从任务实时汇总。

## 可靠性
MySQL 为事实来源，Redis 仅为唤醒通道。扫描器恢复待转换事件、到期步骤、超时租约。步骤原子领取，执行结果以租约 token 校验提交；重复队列消息不会重复领取。所有外部调用均在 DB 事务之外。HTTP 超时 < worker 超时 < 租约过期时间。有限指数退避加抖动；不确定且不支持幂等的请求转人工核对。人工恢复保留历史并保留幂等键。
供应商串行租约及速率限制、有限熔断保护；独立供应商队列；暂停连接不会视为成功。已成功的步骤不会因后续失败被重跑。
跨事件通过同一鉴权来源下的 predecessor_id 显式表达，缺失前序保持等待；禁止循环。无前序声明时不推断业务顺序。

## 配置与管理
业务来源与 Token、供应商连接、API 定义、工作流草稿/发布版本、事件/任务/请求/死信视图。配置发布检查引用、Driver、参数、依赖环、关闭节点依赖。模板支持立即、延迟、每日定时（不聚合）。链路查看跨事件及跨任务依赖，输入/输出映射。管理端 session + CSRF；接入端按业务来源配置独立 bearer token，只存 SHA-256 摘要；来源由鉴权结果注入。请求不含 source 和 business_key。所有写操作审计。

## 边界
不承诺 exactly-once 或供应商业务成功；不做全局事务、自动补偿、自动替代供应商。Driver 可扩展状态查询协议，并负责判定各 API 的业务完成条件；演示协议的 202 进入人工核对，防止误释放依赖。旧通用 Driver 只用于历史任务兼容，不用于新配置。无任意脚本执行；限制目标网络、重定向、HTTP 大小和超时。

## 界面
运维工作台，左侧固定导航，主区表格与横向依赖图。底色 #F3F6FA，正文 #25354A，主色 #246BCE，成功 #187C69，失败 #C34E46，等待 #946A16。中文使用 PingFang SC / 系统无衬线，ID 使用等宽字体。视觉重点为事件转换图，其他页面保持简洁。响应式、键盘焦点可见、状态不只使用颜色。
